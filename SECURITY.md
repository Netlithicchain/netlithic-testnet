# Security

If you find a security problem in Netlithic, please tell us privately first.

Email: **security@netlithicchain.com**

Please don't share it publicly until it's fixed. Include what you found, how to reproduce it,
and what it could affect. We'll reply as soon as we can.

**This is a test network and test coins have no value**, but we treat bugs in key handling,
signing, the node, the faucet and the web wallet seriously, because the same code will run
the real network later.

Never send anyone your backup code, backup file password or private key, including us.
Nobody from Netlithic will ever ask for them.
