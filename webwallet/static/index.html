What is a wallet?

Your wallet is a secret key kept only in this browser, plus an address made from it. The address is safe to share. The secret key lets you send coins, so it never leaves your device. Not even our server sees it.

Why write down a backup?

There is no "forgot password" here. If this browser's data is cleared or the device is lost, your backup code (or backup file plus its password) is the only way back in.

What are contribution points?

You earn points by helping the network, for example by sending transfers or running a node. Points show how much you've taken part.

What is the fee?

Each transfer includes a tiny fee that goes to whoever adds it to the network. On the test network it's paid in test coins, which have no value.
